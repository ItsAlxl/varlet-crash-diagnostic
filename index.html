Varlet Crash Diagnostic
What is Varlet Crash Diagnostic?
Varlet Crash Diagnostic is an open-source tool made by alxl to help users find the most relevant information for what caused Darktide to crash.
By grabbing only the relevant information from your console logs, you will be able to help yourself more easily when you run into issues. If you seek help from other people, you can save them some time by giving them only the information they'd go looking for in the console log anyway.
Feel free to gimme your money if you feel so inclined :)
Where are console logs located?
The directory that contains your console logs is different per platform.
Steam (Windows): %AppData%/Fatshark/Darktide/console_logs/
Xbox / Microsoft Store: %AppData%/Fatshark/MicrosoftStore/Darktide/console_logs/
Steam (Linux): <SteamLibrary>/steamapps/compatdata/1361210/pfx/drive_c/users/steamuser/AppData/Roaming/Fatshark/Darktide/console_logs/
My browser is warning me against uploading files. Is this safe?
Rest assured that this tool does not actually upload any files; all of the processing is done entirely on your own machine, and it never sends any information of any kind to any server.
You don't have to take my word for it! Here's the source code. You can run it locally, if you like.
Paste Crash Message
The crash message usually isn't enough to diagnose an issue. Console logs are far more informative. Specify the console log directory; see above for how to find it.
OR
Provide Specific Console Log
Make sure the console log you select is the log created during the session that ended in a crash. A new console log is created every time the game is launched, not when it crashes or closes. See above for console log location.
